# Contributing to adk-recipes

`adk-recipes` is a curated collection of runnable
[Agent Development Kit](https://adk.dev) (ADK) agent examples. A **recipe**
is a focused, self-contained agent under `core/`, `contrib/`, or `plugins/`
that demonstrates a concrete ADK pattern. Community contributors submit new
recipes to `contrib/`.

**Who reads your recipe?** ADK developers looking for a starting
point or pattern to adapt — and coding agents (AI coding assistants)
reading your recipe on a user's behalf. Both benefit from clear
structure and a focused `README.md`.

## Start here

- **[`CONTRIBUTING.md`](../CONTRIBUTING.md)** — Google CLA and
  community guidelines.
- **[`recipe-checklist.md`](./recipe-checklist.md)** — the
  one-page checklist. Everything you need to submit a recipe.
- **[`recipe-handbook/`](./recipe-handbook/README.md)** — deep
  detail. Read once when you're new; return when a checklist
  item needs more explanation.
