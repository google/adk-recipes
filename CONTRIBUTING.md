# How to contribute

Contributions, bug reports, and feature requests are welcome!

## Contribution process

### Licensing

By submitting a pull request to this repository, you agree that your
contributions will be licensed under the project's
[Apache-2.0 License](LICENSE) (per Section 5 of the Apache License, Version 2.0).

### Code reviews

All submissions require review via GitHub pull requests:

1. Fork the repository and create a feature or fix branch from `main`.
2. Add or update unit tests covering your changes under `tests/`.
3. Open a pull request with a clear description of the problem and solution.

### Running tests locally

Before opening a pull request, please ensure the unit test suite passes locally:

```bash
python3 -m unittest discover -s tests -v
```
