# `contrib/`

Community-contributed ADK recipes. Each recipe is a
self-contained example built by a Google partner team or a
community contributor, covering a specific use case or industry
workflow.

Recipes here are broader in scope than `core/` — they show
complete solutions rather than isolated patterns. Browse them
for inspiration, fork one as a starting point, or contribute a
new one following the guide below.

## Trying a recipe

Browse the folders below. Each recipe has its own `README.md`
with setup and run instructions.

## Contributing to `contrib/`

For the requirements and shipping checklist, see the
[recipe checklist](../docs/recipe-checklist.md). For deeper
