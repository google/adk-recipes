# 📊 BigQuery SQL Reference for Google ADK Agent Analytics

This guide documents the core SQL queries used to compute AI Unit Economics, context caching ROI, thinking token costs, and trace auditing over BigQuery tables and views generated by `adk_tokenomics_plugin.finops.bq_schema.provision_bigquery_table` or Google ADK's upstream `BigQueryAgentAnalyticsPlugin`.

---

## 1. Schema Overview & Native ADK Compatibility

Depending on how your BigQuery dataset was provisioned, two schema shapes exist:

1. **Base Table (`adk_agent_events`) — Shared Across Both Provisioners**:
   - Partitioned by `DATE(timestamp)` and clustered by `agent, session_id`.
   - Includes `timestamp`, `event_type`, `agent`, `session_id`, `invocation_id`, `user_id`, `content`, `attributes`, and `latency_ms`.
   - **Column Type Difference**: Upstream Google ADK's `BigQueryAgentAnalyticsPlugin` types `content`, `attributes`, and `latency_ms` as native BigQuery `JSON`, whereas `provision_bigquery_table` types them as JSON-formatted `STRING`. GoogleSQL's `JSON_VALUE(...)` and `TO_JSON_STRING(...)` work identically across **both** `JSON` and `STRING` columns.
2. **Plugin-Provisioned Analytics View (`v_llm_response` via `provision_bigquery_table`)**:
   - Created by `adk_tokenomics_plugin.finops.bq_schema.provision_bigquery_table` via `CREATE VIEW IF NOT EXISTS` (`ADK_LLM_RESPONSE_VIEW_DDL`).
   - Pre-extracts FinOps convenience columns: `model_version`, `usage_prompt_tokens` (base prompt tokens via `content.usage.prompt` / `prompt_token_count`, excluding tool-use prompt tokens), **`usage_tool_use_tokens`** (`tool_use_prompt_token_count` / `toolUsePromptTokenCount`), `usage_cached_tokens`, `usage_completion_tokens`, **`usage_thinking_tokens`**, `usage_total_tokens`, **`context_cache_hit_rate`**, and **`total_ms`** (alongside `attributes`, `content`, and `latency_ms`).
3. **Upstream ADK `BigQueryAgentAnalyticsPlugin` & Pre-v1.0.2 Native View Note**:
   - Upstream ADK's built-in `BigQueryAgentAnalyticsPlugin` creates per-event trace views (`v_llm_response`, `v_llm_request`, `v_tool_completed`, `v_user_message_received`, `v_agent_starting`, `v_agent_completed`, etc.) that project common event metadata (`timestamp`, `event_type`, `agent`, `session_id`, `invocation_id`) and pre-extracted LLM columns (`model_version`, `usage_prompt_tokens`, `usage_cached_tokens`, `usage_completion_tokens`, `usage_thinking_tokens`, `usage_total_tokens`, `context_cache_hit_rate`, `total_ms`), but **omit** `usage_tool_use_tokens` as well as the raw `attributes` and `content` columns from `v_llm_response` (whereas `provision_bigquery_table` in v1.0.2+ exposes `usage_tool_use_tokens` and retains `attributes`, `content`, and `latency_ms`).
   - Therefore, the **Variant A (`v_llm_response`)** queries in §2–§4 sum `COALESCE(usage_prompt_tokens, 0) + COALESCE(usage_tool_use_tokens, 0)` and never select `attributes` or `content` from `v_llm_response`. If querying a pre-v1.0.2 or upstream-provisioned `v_llm_response` view that lacks `usage_tool_use_tokens` (or if you need raw `attributes`/`content` JSON fields), use the **Variant B — Base Table (`adk_agent_events`)** queries in §2–§4 below (matching `adk-tokenomics finops`'s automatic pre-v1.0.2 view & base-table fallback).

## 2. FinOps KPI Aggregation Query

Calculates total turns, fresh vs. cached tokens, completion tokens, thinking tokens, estimated spend, and context cache savings.

### Variant A — Plugin-Provisioned `v_llm_response` View (`provision_bigquery_table`)

```sql
SELECT
    COUNT(*) AS total_turns,
    COUNT(DISTINCT session_id) AS unique_sessions,
    COALESCE(SUM(GREATEST(0, COALESCE(usage_prompt_tokens, 0) + COALESCE(usage_tool_use_tokens, 0) - COALESCE(usage_cached_tokens, 0))), 0) AS total_fresh_input_tokens,
    COALESCE(SUM(COALESCE(usage_prompt_tokens, 0) + COALESCE(usage_tool_use_tokens, 0)), 0) AS total_input_tokens,
    COALESCE(SUM(usage_cached_tokens), 0) AS total_cached_tokens,
    COALESCE(SUM(usage_completion_tokens), 0) AS total_output_tokens,
    COALESCE(SUM(COALESCE(usage_thinking_tokens, 0)), 0) AS total_thinking_tokens,
    -- Cost Formula (Example Gemini 3.8 Flash Rates):
    -- Note: Total prompt tokens = usage_prompt_tokens + usage_tool_use_tokens (includes usage_cached_tokens).
    -- Fresh Input: $0.75 / 1M | Cached Input: $0.075 / 1M | Output & Thinking: $3.75 / 1M
    ROUND(
        SUM(
            (GREATEST(0, COALESCE(usage_prompt_tokens, 0) + COALESCE(usage_tool_use_tokens, 0) - COALESCE(usage_cached_tokens, 0)) / 1000000.0 * 0.75) +
            (COALESCE(usage_cached_tokens, 0) / 1000000.0 * 0.075) +
            ((COALESCE(usage_completion_tokens, 0) + COALESCE(usage_thinking_tokens, 0)) / 1000000.0 * 3.75)
        ), 5
    ) AS estimated_spend_usd,
    -- Optimization Savings:
    ROUND(
        SUM(COALESCE(usage_cached_tokens, 0) / 1000000.0 * (0.75 - 0.075)), 5
    ) AS cache_savings_usd
FROM
    `{project_id}.{dataset_id}.v_llm_response`
WHERE
    timestamp >= TIMESTAMP_SUB(CURRENT_TIMESTAMP(), INTERVAL 30 DAY);
```

### Variant B — Native `BigQueryAgentAnalyticsPlugin` Base Table (`adk_agent_events`)

Works on both upstream ADK `BigQueryAgentAnalyticsPlugin` (`JSON` columns) and `provision_bigquery_table` (`STRING` columns):

```sql
WITH parsed_turns AS (
    SELECT
        session_id,
        COALESCE(
            SAFE_CAST(JSON_VALUE(content, '$.usage.prompt') AS INT64),
            SAFE_CAST(JSON_VALUE(attributes, '$.usage_metadata.prompt_token_count') AS INT64),
            SAFE_CAST(JSON_VALUE(attributes, '$.usage_metadata.promptTokens') AS INT64),
            SAFE_CAST(JSON_VALUE(attributes, '$.usage_prompt_tokens') AS INT64),
            0
        ) + COALESCE(
            SAFE_CAST(JSON_VALUE(attributes, '$.usage_metadata.tool_use_prompt_token_count') AS INT64),
            SAFE_CAST(JSON_VALUE(attributes, '$.usage_metadata.toolUsePromptTokenCount') AS INT64),
            SAFE_CAST(JSON_VALUE(attributes, '$.usage_tool_use_tokens') AS INT64),
            0
        ) AS prompt_tokens,
        COALESCE(
            SAFE_CAST(JSON_VALUE(attributes, '$.usage_metadata.cached_content_token_count') AS INT64),
            SAFE_CAST(JSON_VALUE(attributes, '$.usage_metadata.cachedContentTokenCount') AS INT64),
            SAFE_CAST(JSON_VALUE(attributes, '$.usage_metadata.cacheReadTokens') AS INT64),
            SAFE_CAST(JSON_VALUE(attributes, '$.usage_cached_tokens') AS INT64),
            0
        ) AS cached_tokens,
        COALESCE(
            SAFE_CAST(JSON_VALUE(content, '$.usage.completion') AS INT64),
            SAFE_CAST(JSON_VALUE(attributes, '$.usage_metadata.candidates_token_count') AS INT64),
            SAFE_CAST(JSON_VALUE(attributes, '$.usage_metadata.candidatesTokenCount') AS INT64),
            SAFE_CAST(JSON_VALUE(attributes, '$.usage_completion_tokens') AS INT64),
            0
        ) AS completion_tokens,
        COALESCE(
            SAFE_CAST(JSON_VALUE(attributes, '$.usage_metadata.thoughts_token_count') AS INT64),
            SAFE_CAST(JSON_VALUE(attributes, '$.usage_metadata.thoughtsTokenCount') AS INT64),
            SAFE_CAST(JSON_VALUE(attributes, '$.usage_metadata.thinkingOutputTokens') AS INT64),
            SAFE_CAST(JSON_VALUE(attributes, '$.usage_thinking_tokens') AS INT64),
            0
        ) AS thinking_tokens
    FROM
        `{project_id}.{dataset_id}.adk_agent_events`
    WHERE
        timestamp >= TIMESTAMP_SUB(CURRENT_TIMESTAMP(), INTERVAL 30 DAY)
        AND (event_type = 'LLM_RESPONSE' OR event_type IS NULL)
)
SELECT
    COUNT(*) AS total_turns,
    COUNT(DISTINCT session_id) AS unique_sessions,
    COALESCE(SUM(GREATEST(0, prompt_tokens - cached_tokens)), 0) AS total_fresh_input_tokens,
    COALESCE(SUM(prompt_tokens), 0) AS total_input_tokens,
    COALESCE(SUM(cached_tokens), 0) AS total_cached_tokens,
    COALESCE(SUM(completion_tokens), 0) AS total_output_tokens,
    COALESCE(SUM(thinking_tokens), 0) AS total_thinking_tokens,
    ROUND(
        SUM(
            (GREATEST(0, prompt_tokens - cached_tokens) / 1000000.0 * 0.75) +
            (cached_tokens / 1000000.0 * 0.075) +
            ((completion_tokens + thinking_tokens) / 1000000.0 * 3.75)
        ), 5
    ) AS estimated_spend_usd,
    ROUND(
        SUM(cached_tokens / 1000000.0 * (0.75 - 0.075)), 5
    ) AS cache_savings_usd
FROM
    parsed_turns;
```

## 3. Provider & Model Breakdown Query

Aggregates consumption, cache efficiency, and latency across models and applications.

### Variant A — Plugin-Provisioned `v_llm_response` View (`provision_bigquery_table`)

```sql
SELECT
    COALESCE(model_version, 'Unknown Model') AS model_name,
    COALESCE(agent, 'default_app') AS app_name,
    COUNT(*) AS turns,
    COALESCE(SUM(GREATEST(0, COALESCE(usage_prompt_tokens, 0) + COALESCE(usage_tool_use_tokens, 0) - COALESCE(usage_cached_tokens, 0))), 0) AS fresh_input_tokens,
    COALESCE(SUM(COALESCE(usage_prompt_tokens, 0) + COALESCE(usage_tool_use_tokens, 0)), 0) AS input_tokens,
    COALESCE(SUM(usage_cached_tokens), 0) AS cached_tokens,
    COALESCE(SUM(usage_completion_tokens), 0) AS output_tokens,
    COALESCE(SUM(COALESCE(usage_thinking_tokens, 0)), 0) AS thinking_tokens,
    COALESCE(SUM(usage_total_tokens), 0) AS total_tokens,
    AVG(context_cache_hit_rate) AS avg_cache_hit_rate,
    AVG(SAFE_CAST(total_ms AS FLOAT64)) AS avg_latency_ms
FROM
    `{project_id}.{dataset_id}.v_llm_response`
GROUP BY
    1, 2
ORDER BY
    turns DESC;
```

### Variant B — Native `BigQueryAgentAnalyticsPlugin` Base Table (`adk_agent_events`)

```sql
WITH parsed_turns AS (
    SELECT
        COALESCE(
            JSON_VALUE(attributes, '$.model_version'),
            JSON_VALUE(attributes, '$.model'),
            JSON_VALUE(content, '$.model_version'),
            'Unknown Model'
        ) AS model_name,
        COALESCE(JSON_VALUE(attributes, '$.session_metadata.app_name'), agent, 'default_app') AS app_name,
        COALESCE(
            SAFE_CAST(JSON_VALUE(content, '$.usage.prompt') AS INT64),
            SAFE_CAST(JSON_VALUE(attributes, '$.usage_metadata.prompt_token_count') AS INT64),
            SAFE_CAST(JSON_VALUE(attributes, '$.usage_metadata.promptTokens') AS INT64),
            SAFE_CAST(JSON_VALUE(attributes, '$.usage_prompt_tokens') AS INT64),
            0
        ) + COALESCE(
            SAFE_CAST(JSON_VALUE(attributes, '$.usage_metadata.tool_use_prompt_token_count') AS INT64),
            SAFE_CAST(JSON_VALUE(attributes, '$.usage_metadata.toolUsePromptTokenCount') AS INT64),
            SAFE_CAST(JSON_VALUE(attributes, '$.usage_tool_use_tokens') AS INT64),
            0
        ) AS prompt_tokens,
        COALESCE(
            SAFE_CAST(JSON_VALUE(attributes, '$.usage_metadata.cached_content_token_count') AS INT64),
            SAFE_CAST(JSON_VALUE(attributes, '$.usage_metadata.cachedContentTokenCount') AS INT64),
            SAFE_CAST(JSON_VALUE(attributes, '$.usage_metadata.cacheReadTokens') AS INT64),
            SAFE_CAST(JSON_VALUE(attributes, '$.usage_cached_tokens') AS INT64),
            0
        ) AS cached_tokens,
        COALESCE(
            SAFE_CAST(JSON_VALUE(content, '$.usage.completion') AS INT64),
            SAFE_CAST(JSON_VALUE(attributes, '$.usage_metadata.candidates_token_count') AS INT64),
            SAFE_CAST(JSON_VALUE(attributes, '$.usage_metadata.candidatesTokenCount') AS INT64),
            SAFE_CAST(JSON_VALUE(attributes, '$.usage_completion_tokens') AS INT64),
            0
        ) AS completion_tokens,
        COALESCE(
            SAFE_CAST(JSON_VALUE(attributes, '$.usage_metadata.thoughts_token_count') AS INT64),
            SAFE_CAST(JSON_VALUE(attributes, '$.usage_metadata.thoughtsTokenCount') AS INT64),
            SAFE_CAST(JSON_VALUE(attributes, '$.usage_metadata.thinkingOutputTokens') AS INT64),
            SAFE_CAST(JSON_VALUE(attributes, '$.usage_thinking_tokens') AS INT64),
            0
        ) AS thinking_tokens,
        COALESCE(
            SAFE_CAST(JSON_VALUE(latency_ms, '$.total_ms') AS FLOAT64),
            SAFE_CAST(JSON_VALUE(latency_ms, '$') AS FLOAT64),
            SAFE_CAST(TRIM(TO_JSON_STRING(latency_ms), '"') AS FLOAT64)
        ) AS turn_latency_ms
    FROM
        `{project_id}.{dataset_id}.adk_agent_events`
    WHERE
        event_type = 'LLM_RESPONSE' OR event_type IS NULL
)
SELECT
    model_name,
    app_name,
    COUNT(*) AS turns,
    COALESCE(SUM(GREATEST(0, prompt_tokens - cached_tokens)), 0) AS fresh_input_tokens,
    COALESCE(SUM(prompt_tokens), 0) AS input_tokens,
    COALESCE(SUM(cached_tokens), 0) AS cached_tokens,
    COALESCE(SUM(completion_tokens), 0) AS output_tokens,
    COALESCE(SUM(thinking_tokens), 0) AS thinking_tokens,
    COALESCE(SUM(prompt_tokens + completion_tokens + thinking_tokens), 0) AS total_tokens,
    AVG(SAFE_DIVIDE(cached_tokens, NULLIF(prompt_tokens, 0))) AS avg_cache_hit_rate,
    AVG(turn_latency_ms) AS avg_latency_ms
FROM
    parsed_turns
GROUP BY
    1, 2
ORDER BY
    turns DESC;
```

## 4. Daily Spend Timeline Query

Used for executive burn charts and forecasting (includes visible output and reasoning/thinking tokens).

### Variant A — Plugin-Provisioned `v_llm_response` View (`provision_bigquery_table`)

```sql
SELECT
    FORMAT_TIMESTAMP('%Y-%m-%d', timestamp) AS date_label,
    COUNT(*) AS daily_turns,
    COALESCE(SUM(usage_total_tokens), 0) AS daily_tokens,
    ROUND(
        SUM(
            (GREATEST(0, COALESCE(usage_prompt_tokens, 0) + COALESCE(usage_tool_use_tokens, 0) - COALESCE(usage_cached_tokens, 0)) / 1000000.0 * 0.75) +
            (COALESCE(usage_cached_tokens, 0) / 1000000.0 * 0.075) +
            ((COALESCE(usage_completion_tokens, 0) + COALESCE(usage_thinking_tokens, 0)) / 1000000.0 * 3.75)
        ), 5
    ) AS daily_spend_usd
FROM
    `{project_id}.{dataset_id}.v_llm_response`
GROUP BY
    1
ORDER BY
    1 ASC;
```

## 5. Event Stream & Trace Audit Query

Streams lifecycle events from `adk_agent_events` for session debugging. Uses `TO_JSON_STRING(content)` and `JSON_VALUE(latency_ms, ...)` so the query compiles and runs identically whether `content` / `latency_ms` are typed as native BigQuery `JSON` (upstream `BigQueryAgentAnalyticsPlugin`) or `STRING` (`provision_bigquery_table`):

```sql
SELECT
    timestamp,
    event_type,
    agent,
    session_id,
    COALESCE(user_id, JSON_VALUE(attributes, '$.user_id'), '') AS user_id,
    COALESCE(TO_JSON_STRING(content), '') AS content_snippet,
    COALESCE(
        SAFE_CAST(JSON_VALUE(latency_ms, '$.total_ms') AS FLOAT64),
        SAFE_CAST(JSON_VALUE(latency_ms, '$') AS FLOAT64),
        SAFE_CAST(TRIM(TO_JSON_STRING(latency_ms), '"') AS FLOAT64),
        0.0
    ) AS latency_ms,
    attributes
FROM
    `{project_id}.{dataset_id}.adk_agent_events`
ORDER BY
    timestamp DESC
LIMIT 50;
```
